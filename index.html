How This DFA Works

  • q0 → q1: The password must contain at least 8 characters.
  • q1 → q2: A lowercase character a-z is detected.
  • q2 → q3: An uppercase character A-Z is detected.
  • q3 → q4: A numeric digit 0-9 is detected.
  • q4 → q5: A special character such as @ # $ % ! is detected.
  • q5: Final accepting state.
DFA = (Q, Σ, δ, q₀, F)
